家安心隱私權政策

更新日期：2026-05-04

1. 適用範圍

本隱私權政策說明「家安心」如何處理你在使用 App 時提供或產生的資料。

家安心是一個服藥、慢箋與家人照護提醒工具。家安心不是醫療診斷、治療建議、劑量計算或緊急服務工具。

  • 開發者 / 服務提供者：沈辰融
  • 聯絡信箱：support@jiaanxin.app
  • Support URL：https://www.jiaanxin.app/support/

2. 我們會處理哪些資料

依你使用的功能不同，家安心可能會處理下列資料：

  • 登入與帳號資料：Firebase UID、家安心 account id、登入方式、手機號碼、Apple 登入識別資訊、顯示名稱與家安心 ID。
  • 服藥與照護資料：服藥日期與時間、家人回應、care reminder、慢箋計畫、領藥 / 抽血 / 回診事件、院所名稱與科別。
  • 家人連結資料：配對關係、家人稱呼、配對狀態與 QR Code 配對資料。
  • 裝置與推播資料：FCM / APNs device token、裝置平台、裝置標籤與 widget session token。
  • 本機資料：App 可能在裝置本機保存必要的登入狀態、服藥紀錄快取、配對與顯示資料。
  • 診斷資料：若使用 TestFlight、Apple 或系統提供的診斷功能，可能會收到 crash logs、基本裝置資訊或測試回饋。

家安心目前不使用 HealthKit，不使用定位功能，不做第三方廣告追蹤，不出售個人資料，也不用相機或相簿上傳醫療報告圖片。

3. 相機與相簿

家安心只在你使用配對功能時要求相機或相簿權限：

  • 相機：掃描家人的配對 QR Code。
  • 相簿：讀取相簿中的配對 QR Code。

相機與相簿權限不是用來收集你的照片內容，也不是用來上傳醫療圖片。

4. 我們如何使用資料

  • 建立、恢復與保護登入 session。
  • 讓你記錄服藥與慢箋提醒。
  • 讓已連結的家人看到照護狀態。
  • 傳送服藥、回應與照護提醒推播。
  • 顯示首頁、家人 feed、慢箋與設定資料。
  • 支援帳號刪除、登出與跨裝置 session 失效。
  • 處理錯誤、維護服務安全與改善 App。

5. 家人分享

當你建立家人連結後，你同意將相關照護資料分享給已連結的家人，例如服藥紀錄、照護提醒、慢箋提醒與回應狀態。

你可以在 App 內移除家人連結。移除連結後，對方不應再看到新的照護更新；但移除前已經同步或顯示過的資料，可能仍短暫保留在對方裝置的本機快取中，直到 App 更新或清理。

6. 第三方服務

家安心可能使用下列服務提供 App 功能：

  • Firebase Authentication：登入與身份驗證。
  • Firebase Cloud Messaging / Apple Push Notification service：推播。
  • Apple Sign in with Apple：Apple 登入。
  • Railway 或其他 backend hosting：後端 API 與資料保存。
  • Apple / TestFlight / 系統診斷工具：crash logs 與測試回饋。

這些服務可能依其政策處理必要的技術資料。

7. 資料保存與刪除

  • 你仍使用帳號時，必要資料會保留以提供同步、提醒、家人連結與推播。
  • 你可以在 App 的「設定 > 資料與帳號 > 刪除帳號」中刪除帳號。
  • 刪除帳號會刪除目前帳號相關資料，包含帳號資料、配對、提醒、服藥紀錄、慢箋資料與裝置 session 等，除非法律要求或安全稽核需要保留特定資料。
  • 刪除帳號後，其他裝置會在偵測到 session 失效後清除本機登入狀態。

訪客登入也會建立臨時登入狀態來使用同步功能。若你沒有綁定手機或 Apple 帳號，換機、重裝或登出後資料可能無法復原。

8. 資料安全

我們會採取合理措施保護資料，例如使用 Firebase session、backend 驗證與裝置 session 管理。但任何網路服務都無法保證絕對安全，請避免在 App 中輸入不必要的敏感資料。

9. 未成年人

若你未達所在地法律規定的同意年齡，請在家長或監護人同意與協助下使用本 App。

10. 跨境處理

家安心使用的雲端服務可能在你所在地以外的地區處理資料。使用本 App 即表示你理解資料可能依服務提供商的基礎設施進行跨境處理。

11. 政策更新

我們可能因功能、法規或服務調整而更新本政策。重大變更會盡量在 App 或相關頁面中提示。

12. 聯絡我們

若你對隱私權政策、資料處理或帳號刪除有問題，請聯絡 support@jiaanxin.app。
